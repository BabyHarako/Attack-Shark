Attack Shark hasn't published a wire protocol for the R11 Ultra, so the buttons above are currently wired up but silent — connecting the device works, but the exact bytes for "set DPI to 3200" etc. aren't known yet. To make a control live: open this panel, connect the mouse, then run Attack Shark's own configurator alongside it and change that one setting. Every inputreport the device sends shows up below. Once you've matched a setting to its bytes, drop the sequence into the PROTOCOL object at the top of this file's script and the matching button will start sending real sendReport() calls.
